# AP2 FIAE Fehlerlog

Jeder Fehler ist eine Information. Trage hier ein, was in Quiz, Trainer, Aufgaben oder Probeprüfungen schiefging – und **warum**. Vor der Prüfung ist diese Liste dein wertvollster Lernzettel.

| Datum | Quelle (Prüfung/Aufgabe) | Thema/Modul | Was ist passiert? | Richtig ist … | Wiederholt am |
|---|---|---|---|---|---|
| | | | | | |

> [!tip] Typische Fehlerursachen
> - **Aufgabe nicht genau gelesen** (z. B. „nennen“ vs. „erläutern“, Anzahl der geforderten Punkte)
> - **Einheit/Umrechnung** (GiB vs. GB, Bit vs. Byte, dezimale Datenrate)
> - **Begriffe verwechselt** (inkrementell/differenziell, RPO/RTO, include/extend)
> - **Flüchtigkeit** im Schreibtischtest oder in der SQL-Syntax

Die Fehlerlogs des Quiz findest du im Dashboard unter „Als Nächstes“ (Schwächen) und im Quiz-Modus „Nur Schwächen“.
